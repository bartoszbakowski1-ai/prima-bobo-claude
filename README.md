# Claude w Prima Bobo: materiały ze szkolenia 23.09.2026

Prowadzący: Bartek Bąkowski

## Co tu jest
| Plik | Do czego |
|---|---|
| `prompty-wywiad.md` | Prompty, dzięki którym Claude przeprowadza z wami wywiad i sam składa pliki kontekstu |
| `prompty.md` | Wszystkie prompty ze szkolenia: odczyt konta, konkurencja, brief, scenariusze, raport |
| `kontekst-szablony/` | Szablony do wspólnego folderu: `CLAUDE.md`, `firma.md`, `produkt.md` |
| `meta-copy/SKILL.md` | Skill /meta-copy: teksty reklam Meta na 5 poziomów świadomości klienta |
| `instrukcja-GA4-w-Claude.md` | Google Analytics 4 w Claude: droga szybka (eksport CSV) i stała (konto usługi) |

## Od czego zacząć
1. Załóżcie na Dysku Google folder „Prima Bobo AI” i skopiujcie do niego `kontekst-szablony/`.
2. W Claude utwórzcie projekt „Prima Bobo”. Wklejcie `CLAUDE.md` jako instrukcję projektu.
3. Uruchomcie prompty z `prompty-wywiad.md`: najpierw firma, potem klient i jeden produkt.
4. Gotowe pliki wgrajcie do projektu. Te same pliki działają w projekcie w ChatGPT.

## Skill /meta-copy
W Claude: Ustawienia, Możliwości (Capabilities), Skille, prześlij folder `meta-copy` spakowany do ZIP. Potem w rozmowie wpisujecie `/meta-copy wanienka składana`.
